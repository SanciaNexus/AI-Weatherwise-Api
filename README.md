# AI WeatherWise API

A backend REST API for an AI-powered weather application built using Node.js, Express.js, MongoDB, and the OpenWeather API.

## Features

- User registration and authentication
- MongoDB database integration
- Weather data integration using OpenWeather API
- REST API endpoints
- Environment variable-based API key configuration
- Secure handling of sensitive information using `.env`

## Tech Stack

- Node.js
- Express.js
- MongoDB
- OpenWeather API
- JavaScript
